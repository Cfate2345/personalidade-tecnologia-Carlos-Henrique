
# 👤 Personalidade da Tecnologia

## Nome

Ada Lovelance

## Quem é?

Ada Lovelace (1815–1852) foi uma matemática e escritora britânica, mundialmente reconhecida como a primeira programadora da história. 

## Principal contribuição

A principal contribuição de Ada Lovelace foi a criação do primeiro algoritmo da história projetado para ser processado por uma máquina

## Relação com Desenvolvimento de Sistemas

Ada Lovelace é considerada a primeira programadora da história. No século XIX, ela escreveu o primeiro algoritmo para ser processado por uma máquina mecânica (a Máquina Analítica de Charles Babbage).

Para que serve o comando git status?
git statusMostra arquivos modificados (modified).
Exibe arquivos novos não rastreados (untracked).
Indica o que está pronto na área de preparo (staging area).

Qual é a função do comando git add?
git addAdiciona alterações à área de preparo (staging area).
Prepara arquivos específicos ou todos para o próximo commit
Para que serve o comando git commit?
git commitSalva de forma definitiva as alterações preparadas no repositório local.
Cria um registro histórico com um código único (hash) e uma mensagem descritiva.
O que podemos visualizar utilizando o comando git log?
Exibe o histórico completo de commits do projeto.
Mostra o autor, a data, o código de identificação e a mensagem de cada alteração.
Qual é a diferença entre git log e git log –oneline?
git log e git log –onelinegit log: Mostra detalhes completos de cada commit em múltiplas linhas.
git log --oneline: Mostra cada commit resumido em apenas uma linha com o código curto e o título.
Para que serve o comando git restore?
Restaura arquivos para o estado do último commit salvo.
O que acontece quando utilizamos:

desfazer alterações na árvore de trabalho (working tree) ou na área de preparação (staging area)
